# Native Salesforce evidence checklist

Each screenshot must come from the authenticated Salesforce org after deployment. Design artwork and the offline browser demo are not native implementation evidence.

- Deployment result and component list, with secrets excluded.
- Dedicated Lightning app and its workbench.
- Native object list and detail pages.
- Before/after operation on fictional seed records.
- Apex test result, failures resolved, coverage reported only from the org.
- Permission and invalid-input cases, with the test actor documented.
- Short walkthrough based on actual captured interactions. If video cannot be captured, deliver a labeled screenshot walkthrough and recording script, never simulated footage presented as a recording.
