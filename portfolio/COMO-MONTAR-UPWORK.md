# Como montar este case no Upwork

Crie um item separado para este projeto. Use a capa, o vídeo Overview e o vídeo de fluxo, nessa ordem. Depois use as capturas originais e o PDF individual. Copie o título, papel, descrição e habilidades de UPWORK-DRAFT.md.

Se o editor do seu perfil não aceitar MP4 direto, publique o vídeo em uma plataforma de vídeo de sua escolha e use a opção de link disponível no formulário. Não existe link público sem login para esta organização Salesforce. Não compartilhe senha.

Os vídeos são explicações editadas a partir de capturas reais, sem áudio. O vídeo de ReUse explica a política e os estados já verificados; não mostra uma aprovação inteira sendo executada. A publicação no Upwork ainda não foi feita.
