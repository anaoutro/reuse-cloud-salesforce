# Native walkthrough — 60 to 90 seconds

Record only the deployed Salesforce application. This is a script, not recorded footage.

0–10 seconds: Open the dedicated Lightning app and state the business problem. Show the Salesforce navigation and label fictional portfolio data.
10–25 seconds: Select a record, explain its inputs and the operational decision.
25–50 seconds: Run the main action. Wait for the real asynchronous job where applicable, refresh, then show the resulting record state.
50–65 seconds: Demonstrate an approval or confirmation. Show the server validation for an inappropriate action on a separate test record.
65–80 seconds: Open the native object details and show the stored results. Show the actual Apex test report.
80–90 seconds: End with Ana Gomes — Salesforce / Apex / LWC. Use subtle captions and clean cuts; never replace the interface with a generated CRM image.

Mask any unrelated private information and exclude credentials, client identifiers and deployment authorization pages from the Upwork video.
